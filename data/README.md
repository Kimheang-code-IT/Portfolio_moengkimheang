# Portfolio data

Edit these JSON files to update portfolio content without changing Vue components:

- `profile.json`: personal details, hero copy, image, and rotating job titles
- `about.json`: biography, current focus, and statistic labels
- `skills.json`: skill section copy, categories, technologies, icons, and colors
- `projects.json`: project section copy, card labels, and project entries
- `experience.json`: work experience and education entries
- `expertise.json`: core expertise labels and proficiency percentages shown in the hero
- `contact.json`: contact copy, form labels, validation rules, and status messages
- `site.json`: navigation, social links, header labels, and footer copy

Use Iconify names such as `i-simple-icons-nuxt` for brand icons and public paths such as `/images/profile.jpg` for local assets.
